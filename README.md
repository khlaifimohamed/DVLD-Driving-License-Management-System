# DVLD - Driving License Management System

## 📌 About the Project

DVLD is a desktop application designed to manage driving license
operations, applicants, applications, tests, and users.

## 🛠 Technologies

- C#
- .NET Framework
- Windows Forms
- SQL Server
- ADO.NET
- 3-Tier Architecture

## ✨ Features

- User authentication
- User management
- People management
- Drivers management
- License management
- Local driving license applications
- Test appointments
- Tests management
- International licenses
- Search and filtering
- Database management

## 🏗 Architecture

Presentation Layer
↓
Business Logic Layer
↓
Data Access Layer
↓
SQL Server

## 🗄 Database

The project uses SQL Server as its relational database.
